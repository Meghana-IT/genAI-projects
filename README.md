# GenAI Projects

This repository contains five Generative AI mini projects built using Python, Streamlit, and Groq API.  
The main goal of these projects is to demonstrate practical use cases of AI in chatbots, summarization, resume analysis, content generation, and code explanation.

## Projects Included

1. AI Chatbot - Custom Assistant
2. Text Summarizer App
3. AI Resume Analyzer
4. AI Content Generator
5. AI Code Explainer Tool

## Technologies Used

- Python
- Streamlit
- Groq API
- LLaMA model
- python-dotenv
- PyPDF2
- pdfplumber
- Git and GitHub

## Workflow

1. User interacts with the Streamlit web interface.
2. User input is collected through text boxes, chat input, dropdowns, or file upload.
3. The input is sent to the Groq API using a custom prompt.
4. The AI model processes the request.
5. The generated response is displayed back in the Streamlit app.
6. Session state is used where chat history is required.

## Why These Projects?

These projects solve real-world problems:

- AI Chatbot helps users ask questions conversationally.
- Text Summarizer helps summarize long articles and PDFs.
- Resume Analyzer helps compare resumes with job descriptions.
- Content Generator creates blogs, LinkedIn posts, and social media content.
- Code Explainer explains programming code in beginner-friendly language.
